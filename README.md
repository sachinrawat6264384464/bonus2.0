# Shrijal Talkar — Modern Vastu Expert & Author

A modern, high-fashion editorial web experience built with **Next.js (App Router)** and **Vanilla CSS Design System** for **Shrijal Talkar**, Gold Medalist in Vastu & Author of *"The Space on Your Side"*.

---

## ✨ Features

- **Luxury Editorial Aesthetic:** Custom Cormorant Garamond typography with signature italics, warm ivory / alabaster theme (`#FAF9F5`), refined charcoal accents, and subtle borders.
- **Concentric Celestial Orbit Geometry:** Authentic circular energy field graphics placed behind hero and portrait frames.
- **Interactive 2-Minute Space Check Assessment:** Interactive 3-step evaluation tool (Business, Home, or Both) delivering instant diagnostic insights without demolition.
- **Direct Consultation Booking Modal:** Clean, accessible scheduling modal with direct client inquiry capture.
- **Interactive Case Studies:** Deep-dive modal displays for Business and Residential Vastu case studies (The Concern, The Observation, The Change, Client's Experience).
- **Published Book Showcase:** 3D book mockup presentation of *"The Space on Your Side: The Modern Vastu of Energy, Light and Flow"*.
- **Responsive Layout:** Pixel-perfect rendering across desktop, tablet, and mobile viewports.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React 19
- **Icons:** Lucide React
- **Styling:** Vanilla CSS (Custom tokens, typography variables, responsive grid system)
- **Fonts:** Cormorant Garamond & Plus Jakarta Sans (Google Fonts)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sachinrawat6264384464/bonus2.0.git
cd bonus2.0
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 4. Build for production
```bash
npm run build
npm start
```
